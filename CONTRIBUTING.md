# Contributing

Contributions are welcome through GitHub issues and pull requests.

## Development

The package requires PHP 8.5 or later.

Install dependencies:

```bash
composer install
```

Run the full check suite before submitting a pull request:

```bash
composer check
```

To apply code formatting:

```bash
composer format
```

Please keep changes focused, add or update tests for behavior changes, and avoid introducing public API changes without documenting them.
